# Java OpenGL Builder
A 3D architectural builder application developed in Java that allows users to interactively assemble structures based on preconfigured blueprints.

## Technical Implementation
* Native Bindings: Leveraged JOGL (Java OpenGL) to interface between the Java Virtual Machine and native C/C++ graphics libraries.
* UI Architecture: Built a custom interactive interface using Java Swing to manage part selection and placement logic.
* Object Logic: Developed a blueprint system that validates user-placed parts against a target model (Leaning Tower of Pisa).
* Real-time Rendering: Managed the rendering loop to update the 3D viewport instantly as users interact with the UI.

## Environment and Dependencies
* Language: Java
* Graphics: JOGL
* UI: Java Swing
* IDE: IntelliJ IDEA
